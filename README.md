# 🚀 Full-Stack Projects

## 🌐 Web Project API Full

🔗 **Live Demo:** https://web-project-api-full-gamma.vercel.app  
🔗 **Repository:** https://github.com/PublioMello/web_project_api_full

A full-stack web application developed as the final project of the TripleTen Software Engineering Bootcamp.

The application combines a **React frontend**, **Node.js/Express backend**, and **MongoDB database**, implementing authentication, authorization, data validation, centralized error handling, logging, and cloud deployment.

### 🔐 Key Features

- User registration
- JWT-based authentication
- Protected routes
- User authorization
- Profile editing
- Avatar updates
- Card creation
- Card deletion
- Like and unlike functionality
- REST API integration
- Data validation
- Centralized error handling
- Request and error logging

### 🖥️ Frontend

- HTML5
- CSS3
